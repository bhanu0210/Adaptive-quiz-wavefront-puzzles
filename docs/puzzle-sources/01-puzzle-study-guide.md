## 2. Deep-Dive Study Guide: Puzzles by Difficulty Tier

### Tier 1: Folk / Introductory Puzzles (Novice Level)
Philosophical Focus: language, semantic flexibility, the absolute baseline of propositional reasoning. Cognitive mechanics: overcoming intuitive heuristics — transitioning from lateral literal interpretations to structured elimination.

### Tier 2: Classic / Algebraic Puzzles (Intermediate Level)
Philosophical Focus: Constraint Satisfaction Problems (CSPs) and the initial boundary of Bayesian belief revision. Cognitive mechanics: working memory and high-dimensional tracking (e.g. Einstein's Zebra requires a 5x5 matrix of 25 relational variables). Monty Hall tests cognitive flexibility against the "equiprobability illusion."

### Tier 3: Epistemic / Recursive Puzzles (Advanced Level)
Philosophical Focus: temporal epistemic logic, public announcements, the structural leap from **Mutual Knowledge** to **Common Knowledge**. Cognitive mechanics: deeply nested theory of mind ("I know that you know that I know...").

### Tier 4: Paradoxical / Decision-Theoretic Puzzles (Expert Level)
Philosophical Focus: anthropic reasoning, causal loops, backward induction failure, competing decision theories (CDT vs EDT vs FDT). Cognitive mechanics: high-level analytical execution, monitoring contradictory cognitive paths.

## 3. Quick-Reference Epistemic & Decision Sheets

### Reference Sheet A: Mutual Knowledge vs. Common Knowledge

```
               [ FACT (p) IS TRUE ]
                        |
            +-----------+-----------+
            |                       |
   [ MUTUAL KNOWLEDGE ]    [ COMMON KNOWLEDGE ]
  "Everyone knows p" (E_G p)   "Everyone knows that everyone knows... p" (C_G p)
            |                       |
  - Transmitted in private        - Transmitted via public announcement
  - No synchronized timeline      - Creates a synchronized timeline (T_0)
  - Logic chains are finite       - Logic chains are infinite (ad infinitum)
  - Cannot trigger countdown      - Triggers recursive countdowns
```

### Reference Sheet B: Causal (CDT) vs. Evidential (EDT) vs. Functional (FDT) Decision Theories

| Decision Theory | Core Rationality Axiom | Action in Newcomb's Paradox | Action in Twin Prisoner's Dilemma | Action in Counterfactual Mugging |
| :--- | :--- | :--- | :--- | :--- |
| **CDT** | Choose the action that *physically causes* the best outcome. | **Two-Box**: the money is already set; choice cannot retroactively change the past. | **Defect**: twin's action is causally independent of my current choice. | **Do Not Pay**: paying Tails has no causal link to Heads-branch money. |
| **EDT** | Choose the action that provides the best *evidence* of a good outcome. | **One-Box**: choosing only Box B is strong evidence the predictor placed $1M inside. | **Cooperate**: my cooperation is evidence my twin will also cooperate. | **Pay**: paying on Tails is evidence of a setup where I win big on Heads. |
| **FDT** | Act as if your decision procedure is the output of a *logical algorithm* run in multiple places. | **One-Box**: the predictor simulates my algorithm; to get $1M the algorithm must output "One-Box." | **Cooperate**: twin runs the *same* algorithm; it must output "Cooperate." | **Pay**: pre-committing to pay on Tails is the algorithmically optimal strategy. |

### Reference Sheet C: The Nested Query Formula (Embedded Question Lemma)

Query = E(Q) = "If I asked you 'Q', would you say 'ja'?"
Boolean reduction: Response = ja  iff  Q = True
