# Puzzle Sources

Durable knowledge base for Wavefront Puzzles' recurring content cycle. These files are the accumulated reference material — full puzzle setups, worked solutions, and validated answers — used to author each 90-puzzle roster.

**Start here**: `../PUZZLE-ROTATION.md` is the actual operating playbook for the every-14-days rotation. This directory is its reference library.

- `01-puzzle-study-guide.md` — taxonomy of puzzle families by difficulty tier and cognitive mechanic, plus quick-reference sheets (mutual vs. common knowledge, CDT/EDT/FDT decision theory, the Embedded Question Lemma).
- `02-epistemic-precursor-and-decision-theory-puzzles.md` — Three Logicians, Boolos' precursor puzzles, Gerbrandy's boxes, Freudenthal Sum & Product, the Provence 2010 variant, Denise's Revenge, Ant-Honey, the n-gods generalization, Bernard-starts Cheryl, Cheating Husbands, Tuesday Boy, Sleeping Beauty, Twin Prisoner's Dilemma, Counterfactual Mugging.
- `03-core-anthology-and-folk-riddles.md` — the Hardest Logic Puzzle Ever (and its variants), Blue-Eyed Islanders, classic Cheryl's Birthday, Newcomb's Paradox, the Unexpected Hanging Paradox, Monty Hall, folk riddles (Sphinx, Belmont Caskets, Harvard Riddle, Prisoner's Lie/Truth), the full Einstein Zebra clue set, GCHQ ciphers, and the explicit **out-of-scope list**.
- `04-tabletop-compendium-background.md` — mostly overlapping background material; flags one riddle with no confirmed answer (do not use), and general "why puzzles matter" copy that isn't puzzle content.
- `05-wits-and-wonders-handbook.md` — TED-Ed's animated logic-riddle series (Einstein's Riddle, the Bridge Riddle, the pyramid Control Room graph puzzle, the Green-Eyed/Blue-Eyed Islanders variant, the Passcode deduction, the Prisoner Hat parity strategy, the River Crossing, the Temple liar puzzle) plus Shakuntala Devi's *The Book of Numbers* and the full 150-puzzle *Puzzles to Puzzle You* catalog. **Only the first three sections (TED-Ed riddles, Book of Numbers, and the 11 fully worked "deep dive" puzzles) carry a shown derivation** — the 150-entry directory is answer-only and needs a full from-scratch re-solve before use, not a spot-check. Several directory entries are flagged out of scope (need a diagram/dissection this text+MC-only site can't render) or answer-ambiguous (source itself shows conflicting figures) — see the flags inline in the file.
- `USED-LOG.md` — which puzzle families are already live or archived, and which available families haven't been used yet. **Update this every cycle.**

When new source material is shared, add it here as a new numbered file in the same style (setup → solution mechanics → validated answer), don't just summarize losslessly — future cycles need to independently re-verify answers, not trust a summary.
